# ![logo](https://i.imgur.com/pGuOGCV.png)
Welcome to Terrain! You'll play as Susie, the rock. 
In this endless game, you will use your axe to chop trees, collect wood, and do upgrades.

![menu](https://i.imgur.com/K8TCnur.png)
![view1](https://i.imgur.com/bbB3O9t.png)

Here are some of the game features and mechanics:

## Map
The map of the game is procedurally generated, in other words
each time you create a new save, a different map will be created

## Time Cycle
The game also has a time cycle system:

![day](https://i.imgur.com/NlzI41F.png)
![dusk](https://i.imgur.com/UUMCgwx.png)
![night](https://i.imgur.com/j4udPDQ.png)

In the images above, you can see there's a full time cycle system
going from morning until dawn.

## Upgrade System
##### Trees
- Each time you break a tree, a new tree with a superior level will
be generated in its place, trees go from **Level 0** up to **Level 10**,
each tree can only be broken by its corresponding axe, so:
- **Tree 0** -> **Axe 0**
- **Tree 1** -> **Axe 1**
- and goes on...

Once you break a **Level 10** tree, this tree will go back to **Level 0**.

##### Axes
- You can also collect wood with the trees you break, to upgrade your axe,
by pressing the **[E]** key, you can open the menu:
![inv](https://i.imgur.com/twzkPUl.png)

The image above is the Upgrader Menu, the main Axe upgrade place, you have
to collect the corresponding wood quantity to upgrade to an upper level of
your axe, also up from **Level 0** to **Level 10**.

### Controls:
- **[W]** - **Move Forward**
- **[S]** - **Move Backward**
- **[D]** - **Move Right**
- **[A]** - **Move Left**
- **[Space]** - **Jump**
- **[E]** - **Opens Upgrade Menu**
- **[ESC]** - **Pause**


And that's it, go explore Terrain, and collect some woods!.
